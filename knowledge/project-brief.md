# Project Brief — Original Context

Complete the capstone in stages:

1. Confirm that the backend is setup correctly and is fully functional
2. Check design docs, and build the React frontend (connect to backend, implement routing navigation, responsive design CSS/Flexbox to make mobile, tablet and desktop compatible)
3. Write tests for 5 UI components
4. Write the AI Feature (build a dedicated route on the app, text analyzer - user pastes text, the app calls Gemini to summarize it, extract key points, or classify its tone)

Follow a quick development cycle, where we work on small features at a time and test that they work as they are developed.
